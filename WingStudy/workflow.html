2. Adaptive shape search

Each shape/span seed evolves independently. Start at the root: test + and − width changes, accept the best positive score change, then move to the next chord. Later passes follow each chord’s remembered winning direction. When it stalls, try one half step and retire that chord, whether or not that refinement succeeds. Default adjustment is 0.02 m. No torque ceilings or cross-seed parent replacement. Zero-width outer sections shorten the actual wing; native Ptera requires two positive sections.

Shared stiffness and damping apply to every native strip. This produces torsional twist, not coupled spanwise beam bending. Material inputs are screening assumptions. Higher damping can suppress response but can also make Ptera's native integrator much slower, especially near narrow tips.

Stiffness starts from the previous 4 mm carbon-rod estimate (assumed E = 34 GPa, 0.10 m reference length). Damping is not calibrated to your fabric or water. Start with a small simulation budget; check repeatability, time step and wake convergence on finalists.

Zero removes that section and every section farther out, shortening the actual wing. Ptera still requires two positive sections. Positive widths obey the minimum-positive-chord setting; individual positive row minima prevent removal.

Score: thrust / Tref − λ × torque / Mref. Tref is the largest absolute seed thrust; Mref is the largest seed torque, fixed once for the study. Default λ = 0.75 gives normalized thrust changes slightly more weight. Score tolerance avoids accepting negligible changes; it is not a calibrated uncertainty bound.

All seeds advance root-to-tip in parallel using the selected number of Ptera processes. The global new-simulation budget includes initial seeds. Exact repeated cases reuse saved results without spending that budget; cached wings retain separate evolution histories. A blocked direction gets its single half-step trial. If neither initial sign improves, test both at half size once and retire the chord. Retired chords stay finished, except a newly exposed tip gets another turn after an outer section disappears: this is a local heuristic, not a convergence certificate. Every simulation is saved, including rejected trials.
