How elasticity modelling changes the results

Each comparison holds outline, motion and numerics fixed, so any difference is the structural model alone. Chordwise elasticity (passive twist about the leading edge) is compared with the same outline as a rigid plate; spanwise + chordwise (bending added) with chordwise alone.
